# Introduction:
This is one guided project I followed from boot.dev after I completed their OOP course, this is a simple video game, based on the classic Asteroids.

# Requirements:
Used Pygame and a virtual environment to manage the project "Unfortunately, Pygame does not yet support Python 3.14. Until it's updated, recommend using Python 3.13."

1. Install Python 3.10+
2. Install uv project/package manager (https://docs.astral.sh/uv/getting-started/installation/)
3. Access to a Unix-like shell (bash or zsh)

# Run:
1. git clone https://github.com/shahbazdalazyprogrammer/asteroids.git
2. Open the cloned directory in your IDE
3. cd asteroids
4. uv sync
5. uv run main.py
